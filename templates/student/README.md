# LLMwiki

「화학공학을 위한 AI」 수업에서 쓰는 개인 지식 위키입니다. 강의에서 들은 것을 임시노트로 받아 두었다가, 자기 말로 다시 쓴 영구노트로 승격시키고, 노트끼리 링크로 이어 붙이는 것이 전부입니다. 규칙은 `CLAUDE.md`에 다섯 줄로 적혀 있고, 이 문서는 폴더와 도구 사용법을 설명합니다.

## 폴더

| 폴더 | 무엇이 들어가나 | 누가 만드나 |
|---|---|---|
| `0.Daily_Notes/` | 하루 한 장. 오늘 만든 것 · 막힌 것 · 틀린 것 | `/llmwiki:daily` |
| `1.Fleeting_Notes/` | 수업 중에 스친 한 줄 생각. 하루 안에 처리합니다 | `/llmwiki:capture` |
| `2.Literature_Notes/` | 강의록·교재·논문을 읽고 만든 문헌노트. 교수가 배포한 강의록은 `Lectures/`에 들어갑니다 | `/llmwiki:literature`, 주2 정리기 |
| `3.Permanent_Notes/` | 자기 말로 쓴 영구노트. 루만 번호와 `slipbox/index.md`는 스크립트가 관리합니다 | `/llmwiki:promote` |
| `4.Project/` | 수업에서 만든 도구가 읽고 쓰는 자리 | 도구 |
| `_meta/` | `promotion-log.jsonl` — 승격 판정 기록 | 스크립트 |
| `_reports/` | 마일스톤 보고서 `.md`·`.json` | `/llmwiki:status` |

각 폴더의 `_template.md`는 새 노트의 서식입니다. 직접 고칠 일은 없습니다.

## 매주 15분 의식

실습 마지막 15분에 아래 네 줄을 그대로 실행합니다. 이 15분이 빠지면 그 주의 기록은 남지 않습니다.

1. `/llmwiki:daily` — 오늘 만든 것, 막힌 것, 틀린 것을 세 칸에 적습니다.
2. `/llmwiki:promote --only 오늘` — 오늘 쌓인 임시노트를 훑어 승격 후보를 올립니다. 게이트가 HOLD를 내면 이유를 읽고 그 자리에서 고칩니다.
3. `/llmwiki:status` — 노트 수, 고아 노트, 성장 태그 승급 후보를 확인합니다.
4. `git add -A && git commit -m "wiki: <날짜>" && git push` — 오늘 것을 원격 저장소에 올립니다.

승격 게이트는 세 가지를 봅니다. 인용을 뺀 본문의 원문 중복률이 20%를 넘지 않을 것, 주제 태그가 하나 이상 있을 것, 다른 노트로 나가는 링크가 두 개 이상 있을 것(영구노트가 다섯 개 미만인 초기에는 한 개). 셋 중 하나라도 걸리면 점수와 무관하게 HOLD입니다.

## 도구 계약

수업에서 만드는 도구는 이 위키의 정해진 자리에만 쓰고 읽습니다. 경로와 형식이 계약이므로 바꾸지 않습니다.

**주2 강의록 정리기** — 강의록을 받아 문헌노트 한 장을 씁니다.

- 쓰는 곳: `2.Literature_Notes/Lectures/YYYY-MM-DD_<주제>.md`
- 형식: 하이라이트마다 원문을 `>` 인용으로 옮기고, 바로 아래에 `**나의 메모**:` 로 자기 말 해석을 붙입니다. `2.Literature_Notes/_template.md`와 같은 모양입니다.

**주3 플래시카드 웹앱** — 영구노트에서 문제를 만들고 푼 결과를 기록합니다.

- 읽는 곳: `3.Permanent_Notes/*.md` (읽기만 합니다. 고치지 않습니다)
- 쓰는 곳: `4.Project/flashcards/results.jsonl` (한 줄에 한 판, 덧붙이기만 합니다)

## 채점 자료

아래 두 가지가 채점의 근거입니다. 지우거나 손으로 고치면 그 주의 활동은 없었던 것이 됩니다.

- `_meta/promotion-log.jsonl` — 승격을 시도할 때마다 한 줄이 붙습니다. 판정(PASS·HOLD·DROP), 다섯 기준 점수, 게이트가 잰 중복률·링크 수·태그 수, 부여된 루만 번호가 들어 있습니다. HOLD도 기록이며 감점 사유가 아닙니다. 시도하지 않은 것이 감점입니다.
- `_reports/milestone_YYMMDD_wNN.md` / `.json` — 주5·10·15 마일스톤에서 만드는 집계입니다. 폴더별 노트 수, 임시노트 처리 비율, 성장 태그 분포, 노트당 평균 링크 수, 고아 노트 목록, 주차별 승격 건수가 표로 정리됩니다. `.json`은 교수 집계 스크립트가 읽습니다.

저장소는 private이고 교수(`SHSUN76`)가 collaborator로 초대되어 있습니다. 커밋과 푸시를 하지 않으면 위 두 자료가 전달되지 않습니다.
