# 오늘의 일일노트

인자: `$ARGUMENTS`

학생이 오늘 한 일을 자기 문장으로 남기는 것이 목적이다. **LLM은 학생의 문장을 고치지 않는다.** 맞춤법도, 어색한 표현도, 짧은 문장도 그대로 둔다.

## 0. 준비

설정을 읽는다. 인자는 없다.

```
python "${CLAUDE_PLUGIN_ROOT}/skills/_shared/scripts/wikiconf.py"
```

`{"error": ...}`(종료 코드 2)면 "LLMwiki 폴더 안에서 실행하세요"를 안내하고 멈춘다. `<root>`와 `paths.daily`는 이 JSON에서 읽는다.

## 1. 오늘 파일 확보

오늘 날짜는 KST 기준 `YYYY-MM-DD`다. 대상 파일은 `<root>/<paths.daily>/YYYY-MM-DD.md`.

- 파일이 이미 있으면 Read해서 어느 칸이 비었는지 확인하고 2단계로 간다. **기존 내용은 지우지 않는다.**
- 없으면 `<root>/<paths.daily>/_template.md`를 Read해서 `{{date}}`를 오늘 날짜로 치환한 내용으로 새로 만든다. 템플릿에 없는 칸을 임의로 추가하지 않는다.

## 2. 세 칸 채우기 (한 번에 하나씩)

템플릿의 세 칸을 **순서대로 하나씩** 묻는다. 세 개를 한꺼번에 묻지 않는다.

| 칸 | 묻는 말 |
|---|---|
| `## 오늘 만든 것` | 오늘 직접 만들거나 돌려 본 것이 무엇입니까? |
| `## 막힌 것` | 오늘 막힌 지점은 무엇입니까? |
| `## 틀린 것 · 배운 것` | 오늘 틀렸던 것, 또는 새로 알게 된 것은 무엇입니까? |

답을 받으면 **받은 문장을 그대로** 해당 칸 아래에 적는다. 요약하지 않고, 문장을 늘리지 않고, 존댓말·반말도 바꾸지 않는다. 이미 내용이 있는 칸은 다시 묻지 않고 건너뛴다.

학생이 "없다"·"패스"라고 하면 그 칸은 비운 채로 둔다. 대신 쓰지 않는다.

## 3. 저장과 퇴실 조건

Edit 도구로 해당 칸의 줄만 고친다. 파일 전체를 다시 쓰지 않는다.

세 칸 중 빈 칸이 있어도 저장은 한다. 저장한 뒤 빈 칸을 알린다.

`퇴실 조건 미충족: <칸 이름>`

빈 칸이 둘 이상이면 이름을 쉼표로 잇는다. 세 칸이 모두 찼으면 `퇴실 조건 충족`이라고 알린다.

## 4. 승격으로 잇기

마지막에 묻는다.

`오늘 쌓인 임시노트를 승격해 볼까요? (/llmwiki:promote --only 오늘)`

승낙하면 `promote` 스킬을 `--only 오늘` 인자로 이어서 실행한다. 거절하면 여기서 끝내고 다음 한 줄을 안내한다.

`git add -A && git commit -m "wiki: <오늘 날짜>" && git push`

## 출력 계약 (hard constraints)

- [ ] 학생의 문장을 한 글자도 고치지 않았다 (맞춤법·어투·길이 포함)
- [ ] 세 칸을 한 번에 하나씩 물었다
- [ ] 이미 채워진 칸을 덮어쓰지 않았다
- [ ] 빈 칸이 있으면 `퇴실 조건 미충족: <칸 이름>`을 알렸다
- [ ] 파일은 줄 단위로만 고쳤다
- [ ] 폴더 이름은 설정의 `paths.daily`에서 읽었고 손으로 적지 않았다
